Official assessment structure in the supplied syllabus

  • CIE = 50 marks and SEE = 50 marks.
  • Each experiment report can be evaluated for 30 marks.
  • Total report marks are scaled to 30.
  • Laboratory test is for 50 marks and is scaled to 20.
  • Final CIE = report component + test component = 50.
This page follows those values rather than inventing a different CIE split.
