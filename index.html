Recommended workflow

  1. Configure the college and course information.
  2. Review the syllabus and course outcomes.
  3. Prepare teaching and student/attendance records.
  4. Conduct experiments and record assessment evidence.
  5. Use the complete manual for faculty teaching and student journals.
  6. Generate CO/PO/PSO evidence and reports.
  7. Back up the local data periodically.

GitHub Pages deployment

Keep this index.html and the six phase HTML files in the same repository directory.

Important: GitHub Pages hosts the static HTML files. Browser LocalStorage is device/browser-specific, so faculty and student data is not automatically shared between different computers.

Source and academic-use note

The course structure and experiment list should be maintained from the college's applicable syllabus/regulations. Detailed command demonstrations and journal guidance in Phase 5 are instructional expansions, not claims that every command or wording is verbatim VTU text.
