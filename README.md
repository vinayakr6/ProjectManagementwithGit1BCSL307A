# Project Management with Git

A GitHub Pages–ready academic management system for **Project Management with Git (1BCSL307A)**. It provides a structured six-phase workflow covering the course syllabus, teaching and attendance, assessment and rubrics, CO–PO/PSO attainment, a complete 12-experiment laboratory manual, and settings/data/AI-assisted academic tools.

The system is designed for **faculty teaching, student learning, laboratory journal reference, assessment, and academic documentation**, with easy navigation between all phases.

> **Technology:** HTML, CSS, JavaScript, Browser LocalStorage
> **Deployment:** GitHub Pages
> **Course:** Project Management with Git – 1BCSL307A
> **Semester:** III

**Note:** Detailed laboratory procedures and journal guidance are instructional expansions of the prescribed experiment tasks. Official academic implementation should follow the applicable final VTU/institutional regulations.
